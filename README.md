🚀 UPI Transactions Analysis Dashboard
📌 Project Overview
This project delivers a comprehensive, data-driven analysis of Unified Payments Interface (UPI) transaction flows, combining advanced data preprocessing with an interactive analytical dashboard. Leveraging a rich simulated dataset of 502,887 transactions totaling over ₹44.25 Crores in volume, this repository explores consumer spending behavior, platform market shares, geographic distribution, and risk-scoring mechanisms across India's digital payment ecosystem
🛠️ Tech Stack & ToolsData Processing & Analysis:
Dataset Scale: 500,000+ transactional records across multiple states and merchant categories 
Visualization & Dashboarding: Excel (Advanced formulas, Pivot Tables, interactive slicers) / Power BI style analytical layout   
Version Control: Git & GitHub
📊 Key Dashboard Insights & Metrics
Total Transaction Volume: ₹44.25 Cr processed across various merchant categories (Bill Payments, P2P transfers, Online Shopping, and Fuel).   
Platform Dominance: PhonePy (PhonePe) leads market share at 49.75%, followed by Google Pay (21.31%) and Paytm (14.34%).   
System Reliability: Maintained an overall success rate of 91.00%, with detailed failure-reason categorization for declined or dropped transfers.   
Risk & Fraud Mitigation: Identified and flagged 17,089 suspected fraud cases using customized risk scores and anomaly detection filters.   
Rewards Ecosystem: Distributed ₹34.63 Lakhs in total cashbacks to incentivize user engagement across platforms.
